# Development Dependencies

Install these in addition to `requirements.txt` for local development, testing, and documentation.

```bash
pip install -r requirements.txt        # Core dependencies
pip install -r requirements_dev.txt    # Development tools
pip install -r requirements_scale.txt  # (Optional) Distributed training
```

## Installation

### Minimum (just testing)
```bash
pip install pytest pytest-cov black ruff mypy
```

### Full Development Setup (recommended)
```bash
pip install -r requirements.txt requirements_dev.txt
pre-commit install
```

### All Features (including distributed)
```bash
pip install -r requirements.txt requirements_scale.txt requirements_dev.txt
pre-commit install
```

## Usage

### Run Tests
```bash
pytest                              # All tests
pytest tests/test_utils.py         # Specific file
pytest -v --cov=agents            # With coverage reporting
pytest -x -vv                      # Stop on first failure, verbose
```

### Format & Lint Code
```bash
black src/ tests/          # Format Python files
isort src/ tests/          # Sort imports
ruff check src/            # Fast linting
mypy src/                  # Type checking
```

### Generate Documentation
```bash
sphinx-build -b html docs/ docs/_build/
# Open docs/_build/index.html in browser
```

### Profile Performance
```bash
python -m cProfile -s cumtime script.py  # CPU profiling
python -m memory_profiler script.py      # Memory profiling
kernprof -l -v script.py                 # Line profiling
```
